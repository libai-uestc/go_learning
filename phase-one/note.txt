go语言在以下情况自动加了分号
1. 如果一行它最后是一个标识符的话，比如像string、int这些标识符，它就会自动帮我们加分号
2. 如果一行的末尾是一个字面量的话，比如18，比如"libai"这个字面量
3. 如果一行的末尾它是break、continue、return等这些关键词的话，也会默认加分号
4. 如果一行的末尾它是以++、--、)、}、]，右侧的，它也会默认地加分号

"comma ok" 惯用法
value, exists := m["语文"]
在 Go 语言中，当你从 map 中获取一个 key 的值时，它可以同时返回两个结果：

value (第一个返回值): 这是 key 对应的实际数据。如果 key 存在，它就是真实的值（比如代码里初始化的 0）。如果 key 不存在，Go 语言不会报错，而是会返回该类型的零值（因为你的 map 值是 int 类型，所以零值就是 0）。

exists (第二个返回值): 这是一个布尔值（true 或 false），在 Go 语言中大家习惯把它命名为 ok 或者 exists。如果 key 在 map 中确确实实存在，它就是 true；如果不存在，它就是 false。

内核线程是操作系统提供的，go程序员不能直接使用内核线程，只能创建Goroutine
M本质上就是一个结构体，M和内核线程是一对一对关联的
当M因系统调用而阻塞，P需要跟其他M绑定，此时M的数量多于P的数量
P的数量上限默认是CPU的总核数，也可以通过runtime.GOMAXPROCS显示指定
P和M的关联关系是变动，G和P的关联关系是变动，所以G和内核线程的关联关系是变动的
所有的G由runtime统一调度，众G平等，不可以指定G的优先级，一个G不会影响另一个G的生命周期
